# React Native Map App

Приложение на React Native и Expo с картой, локальной базой данных, геолокацией и локальными уведомлениями.

Приложение позволяет добавлять маркеры на карту, сохранять их в SQLite, добавлять изображения к маркерам, отслеживать текущее местоположение пользователя и отправлять локальные уведомления при приближении к сохранённым точкам.

## Установка и запуск

Сначала нужно установить зависимости:

```bash
npm install
```

Дополнительные зависимости для задания 3:

```bash
npx expo install expo-location expo-notifications
```

После установки зависимостей запустить проект:

```bash
npx expo start
```

Для тестирования можно использовать Expo Go, Android Emulator или iOS Simulator.

- добавление маркеров долгим нажатием;

- удаление маркера;
- отображение текущего местоположения пользователя;
- запрос разрешения на доступ к геолокации;
- отслеживание местоположения в реальном времени, пока приложение активно;
- вычисление расстояния между пользователем и сохранёнными маркерами;
- отправка локального уведомления при приближении к маркеру;
- предотвращение повторных уведомлений для одной и той же метки;
- повторное разрешение уведомления после выхода пользователя из зоны маркера;

## Геолокация

Работа с геолокацией вынесена в:

```text
src/services/location.ts
```

Для получения координат используется `expo-location`.

При запуске приложение запрашивает разрешение на доступ к местоположению.

Если пользователь не разрешил доступ, приложение сохраняет сообщение об ошибке и не запускает отслеживание.

Для обновления местоположения используется:

```text
Location.watchPositionAsync()
```

Настройки отслеживания:

```text
accuracy: Location.Accuracy.Balanced
timeInterval: 5000
distanceInterval: 5
```

Текущая позиция пользователя отображается на карте через `react-native-maps`.

## Вычисление расстояния

Расстояние между пользователем и маркером вычисляется в:

```text
src/services/location.ts
```

Используется формула Хаверсина.

Функция получает координаты пользователя и координаты маркера и возвращает расстояние в метрах.

Для проверки приближения используется порог:

```text
100 метров
```

Если расстояние до маркера меньше или равно этому значению, приложение пытается показать локальное уведомление.

## Локальные уведомления

Работа с уведомлениями вынесена в:

```text
src/services/notifications.ts
```

Для уведомлений используется:

```text
expo-notifications
```

При запуске приложения запрашивается разрешение на показ уведомлений.

Если разрешение не выдано, ошибка сохраняется и выводится пользователю.

Уведомление отправляется сразу при входе пользователя в зону маркера.

Текст уведомления:

```text
Вы рядом с меткой!
Вы находитесь рядом с сохранённой точкой.
```

## Стратегия управления уведомлениями

Для предотвращения повторных уведомлений используется класс `NotificationManager`.

В памяти хранится:

```typescript
Map<number, ActiveNotification>
```

Ключом является `markerId`.

Для каждого активного уведомления сохраняются:

- идентификатор маркера;
- идентификатор уведомления;
- время создания уведомления.

Перед отправкой нового уведомления проверяется, есть ли уже активная запись для этого маркера.

Если запись существует, новое уведомление не создаётся.

Если пользователь остаётся внутри зоны, повторное уведомление не отправляется.

Когда пользователь выходит из зоны маркера, активная запись для этого маркера удаляется.

После этого при повторном приближении к той же точке уведомление может появиться снова.

## Работа с несколькими маркерами

При каждом обновлении местоположения приложение проверяет расстояние до всех сохранённых маркеров.

Для каждого маркера отдельно определяется:

- находится ли пользователь внутри зоны;
- было ли уже отправлено уведомление;
- нужно ли удалить активное уведомление после выхода из зоны.

## Обработка ошибок

### Геолокация

Обрабатываются:

- отказ пользователя в разрешении на геолокацию;
- отключённые службы геолокации;
- ошибки получения текущего местоположения;
- ошибки при запуске отслеживания координат.

### Уведомления

Обрабатываются:

- отказ пользователя в разрешении на уведомления;
- ошибки при создании локального уведомления;
- ошибки при удалении активного уведомления.

## Тестирование

### Тестирование геолокации

Для тестирования можно использовать iOS Simulator или Android Emulator.

На iOS Simulator тестовое местоположение можно изменить через:

```text
Device → Location
```

На Android Emulator тестовые координаты можно задать через:

```text
Extended Controls → Location
```

Рекомендуемые сценарии:

1. Разрешить доступ к геолокации и проверить отображение текущего местоположения.
2. Отказать в разрешении и проверить обработку ошибки.
3. Создать маркер рядом с тестовой позицией.
4. Изменить координаты так, чтобы пользователь оказался внутри зоны маркера.
5. Проверить появление локального уведомления.
6. Убедиться, что повторные уведомления внутри зоны не появляются.
7. Выйти из зоны маркера.
8. Вернуться в зону и проверить повторное уведомление.
9. Проверить несколько маркеров одновременно.

### Тестирование уведомлений

Нужно проверить:

- разрешение уведомлений;
- отказ в разрешении;
- приближение к одному маркеру;
- приближение к нескольким маркерам;
- отсутствие дублирующихся уведомлений;
- выход из зоны маркера;
- повторное приближение после выхода из зоны.

## Известные ограничения

Отслеживание местоположения реализовано через `Location.watchPositionAsync` и работает, пока приложение активно.

Фоновое отслеживание местоположения в текущей версии не реализовано.

Активные уведомления хранятся только в памяти приложения.

После полного перезапуска приложения список активных уведомлений очищается.

Используются локальные уведомления. Push-уведомления с сервером не реализованы.

Точность определения местоположения зависит от устройства, GPS и системных настроек.

## Дополнительные реализованные функции

Так как приложение является продолжением предыдущих заданий, также реализованы:

- локальная база данных SQLite;
- сохранение маркеров после перезапуска приложения;
- сохранение URI изображений;
- связь маркеров и изображений через внешний ключ;
- автоматическое удаление связанных изображений при удалении маркера;
- React Context для доступа к базе данных;
- обработка ошибок базы данных;
- отображение состояния загрузки;
- динамический экран каждого маркера через Expo Router.

## Хранение данных

Маркеры и изображения сохраняются в SQLite.

Геолокация пользователя в базе данных не сохраняется.

Активные уведомления также не сохраняются в SQLite и существуют только в памяти приложения во время текущего запуска.
